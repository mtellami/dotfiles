# Debugging Workflow

1. Reproduce the problem.
2. Read the complete error.
3. Identify the failing subsystem.
4. Trace execution to the root cause.
5. Form a hypothesis.
6. Verify the hypothesis.
7. Implement the smallest correct fix.
8. Test the fix.
9. Check for regressions.
10. Explain the root cause.
