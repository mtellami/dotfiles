# Research Workflow

1. Define the exact question.
2. Inspect the project's current implementation if relevant.
3. Check official documentation first.
4. Check official repositories/specifications.
5. Compare viable alternatives.
6. Verify version compatibility.
7. Identify limitations.
8. Identify security/performance implications.
9. Provide sources.
10. Separate facts from assumptions.
